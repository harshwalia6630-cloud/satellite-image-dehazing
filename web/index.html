How it works

  1. 1

    Physics-based training data

    Clean satellite scenes get synthetic haze from the atmospheric scattering model I = J·t + A(1−t). Smooth fractal fields make the haze non-uniform, as real haze is.

  2. 2

    Encoder-decoder

    Three stride-2 encoder stages and a residual bottleneck feed three upsampling stages with skip connections. The network predicts a residual that is added back to the input.

  3. 3

    Patch-based reconstruction

    Images are split into overlapping 256 px patches, and each patch is restored separately. Raised-cosine blending removes seams, so images of any size fit in memory.

  4. 4

    In the browser

    The Keras model is exported to ONNX and runs on ONNX Runtime Web (multithreaded WebAssembly). Your images never leave the device.

Honest notes

  • Training and test haze are synthetic, generated with the same physics model on different images. That gives exact ground truth, but real haze can differ.
  • The NASA samples are MODIS images at 250 m to 1 km per pixel, far coarser than the 0.2 to 30 m training imagery. They show how the model generalises; there is no ground truth for them.
  • Thick haze that hides the ground completely cannot be recovered. The model can only restore what is still faintly visible.
